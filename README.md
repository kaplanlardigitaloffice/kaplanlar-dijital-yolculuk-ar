# Kaplanlar WebAR V28

Bu sürümde kamera kontrolleri eklendi:
- sol altta kamera zoom in / zoom out
- 0.5x geniş açı modu (destekleyen cihazlarda gerçek geniş lens, diğerlerinde minimum zoom fallback)
- 16:9 yatay çekim modu (mümkünse fullscreen + orientation lock)
- sağ altta maskot boyut kontrolü korunur

Not: Kamera zoom ve geniş açı desteği cihaz / tarayıcı yeteneklerine göre değişir.
